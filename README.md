
# Taskora - Task Management Dashboard

A modern and responsive task management application built with React.js.

## About the Project

Taskora is a productivity dashboard designed to help users
organize tasks, manage projects, and track their progress.

## Features

- Interactive Dashboard
- Create New Tasks
- Edit Existing Tasks
- Delete Tasks
- Task Categories
- Priority Management
- Todo, In Progress and Done Status
- Drag and Drop Task Management
- Calendar View
- Analytics Dashboard
- User Profile Settings
- Dark and Light Mode
- Local Storage Data Saving
- Responsive User Interface

## Technologies Used

- React.js
- JavaScript
- CSS3
- Vite
- Lucide React
- HTML5

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Open project folder:

```bash
cd taskora
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.
